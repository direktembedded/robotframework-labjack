# Robot Framework LabJack Library

LabJackLibrary, is a library for
[Robot Framework](https://github.com/robotframework/robotframework/blob/v6.1/COPYRIGHT.txt)
from [Robot Framework Foundation](https://robotframework.org/) and wraps
[LabJackPython](https://github.com/labjack/LabJackPython/blob/master/LICENSE) library
from [LabJack Corporation](https://labjack.com/).
